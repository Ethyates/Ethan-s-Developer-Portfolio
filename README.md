# Project 1 - Developer Portfolio Starter

## Overview

This project was created for **ITT-072 Web Scripting 2** using **Vite** and modern JavaScript.

The goal of this project was to learn the modern front-end development workflow by creating, building, and deploying a Vite application while demonstrating JavaScript modules, dynamic content rendering, and responsive design.

---

## Features

* Modern Vite project setup
* Responsive developer portfolio homepage
* JavaScript module imports and exports
* Dynamic rendering of:

  * Technical skills
  * Course goals
  * Featured projects
  * Current focus
* Interactive button with JavaScript event handling
* Responsive card-based layout
* Production build using Vite
